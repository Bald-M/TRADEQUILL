> 版本 v0.14 · 2026-11-20 · 标记含义见总览

## 1. 为什么要做【已确认】

新手不知道一款产品上架后每天该做什么。手册的办法是"找到想超越的对手，分析它的打造节奏，用单量去追赶"（手册 6.13），并每天记录《每日竞品数据统计表》，写下竞品的调价、差评、促销、秒杀、优化，以及自己的思考（手册 6.14）。

这件事要每天做、持续几个月，人工很难坚持。平台让 Agent 每天自动记录、自动发现变化、总结打法，人只看结论和建议。

## 2. 目标

| 目标                 | 衡量方式【建议】                                                     |
| -------------------- | -------------------------------------------------------------------- |
| 不漏掉竞品的关键动作 | 调价、优惠券、秒杀、断货、Listing 改动在 24 小时内被发现             |
| 看懂别人怎么打起来的 | 每个对标竞品有一条"打法时间轴"：上架后每周的价格、排名、评论数、促销 |
| 给出能执行的模仿动作 | 每条建议写清"做什么、做到什么程度、依据是哪个竞品的哪段数据"         |
| 次数可控             | 每个产品每天的卖家精灵消耗不超过设定上限                             |

## 3. 范围

**做：**

- 学习竞品的**运营动作**：定价和调价节奏、优惠券力度、秒杀 / 促销时机、评论积累速度、Listing 改版（标题、五点、图片数量、A+、视频）、变体和组合、关键词布局、断货时间。
- 推算竞品的打造节奏，套用手册 4.8 的 80 天时间轴，给出我们每个阶段的价格、优惠、目标单量建议。

**不做（反目标）：**

- 复制竞品的图片、文案、A+ 内容（只提炼卖点方向，文字和图片必须原创）。
- 使用竞品商标、品牌词作为我方 Listing 内容；外观或功能可能涉及专利的模仿动作要标红提示人工排查。
- 刷单、刷评、操纵评论、恶意攻击竞品（差评、恶意买空、跟卖）——平台不提供任何此类功能。
- 绕过数据源条款直接抓取亚马逊页面。

### 4.1 选对标竞品（手册 6.13）

- 产品风格一致、满足的应用场景一致，不限于同款同材质。
- 小类目：选榜单排名靠前者；大类目：选近期上架且销量达到我们目标的卖家（如 New Release 第 1 名）。
- 建议按"头部 1–2 个 + 近期打起来的新品 2–3 个 + 和我们价位相同的 1–2 个"组合，共 3–7 个【建议】。
- Agent 给候选和理由，人确认后开始跟踪；可随时增删。

### 4.2 建档回溯

对每个对标竞品，用卖家精灵的历史趋势数据回溯（不额外消耗每日快照次数）：

- 上架日期、每周价格、大小类排名、估算销量、评论数和星级的曲线。
- Agent 据此画出"打法时间轴"：第几周开始提价、每次提多少、什么时候开始有优惠、评论多久从 0 到 30 / 100。
- 推算留评率（评论增量 ÷ 估算销量增量），评论增速异常时标注"可能非自然"，不作为模仿依据。

### 4.3 每日快照【建议：每天 1 次，北京时间早上】

| 字段         | 说明                                                                 |
| ------------ | -------------------------------------------------------------------- |
| 价格         | 售价、划线价、优惠券（金额或比例）、Prime 专享价、是否秒杀 / Deal    |
| 排名         | 大类、小类 BSR                                                       |
| 销量         | 卖家精灵估算日销 / 月销                                              |
| 评论         | Ratings 数、Reviews 数、星级；新增差评摘要                           |
| 库存状态     | 是否有货、是否显示"仅剩 N 件"、配送时效变化                          |
| Listing 指纹 | 标题、五点、主图、图片数、A+、视频、变体数的摘要；变化时保存前后版本 |
| 关键词       | 核心词自然排名和广告位（按需，消耗较多次数，默认每周 1 次）【建议】  |

### 4.4 变化识别（平台规则，非 Agent 主观判断）

| 事件                | 判定                                     |
| ------------------- | ---------------------------------------- |
| 调价                | 售价或券后价变动 ≥ $0.2                  |
| 开 / 关优惠券、秒杀 | 状态变化                                 |
| 断货 / 低库存       | 无货，或显示剩余件数                     |
| 排名跃升 / 下滑     | 小类排名 7 日变化超过阈值                |
| 评论异常            | 单日新增评论远高于其销量对应的正常留评率 |
| Listing 改版        | 指纹字段变化                             |

- 重要事件（竞品断货、大幅降价、开秒杀）即时提醒负责运营，并通知 04（可能影响我们的销量预测）。

### 4.5 周度总结与模仿建议

Agent 每周为每个我方产品写一份总结，平台按固定模板渲染：

1. **本周竞品发生了什么**：按事件列表。
2. **它们处在打法的哪个阶段**：对照 80 天时间轴。
3. **我们处在哪个阶段、离目标差多少**：上架后用自家数据对比。
4. **建议动作**（每条进入「待处理建议」）：

| 类型    | 示例                                                                                                                 |
| ------- | -------------------------------------------------------------------------------------------------------------------- |
| 定价    | "竞品 B 上周从 $15.99 提到 $16.49 后销量未降；我们当前 $13.99、日均 8 单，建议本周提价 $0.20（手册：单次 $0.2–0.3）" |
| 优惠券  | "竞品 A 第 3–4 周用 20% 优惠券；我们处于第 3 周，建议设 20%，并设置单单限购 1–2 件"                                  |
| Listing | "4 个竞品主图都加了尺寸标注，我们没有；建议补拍（需原创）"                                                           |
| 关键词  | "竞品 C 新出现在 xxx 词前 10，我们未覆盖；建议加入自动广告观察"                                                      |
| 时机    | "竞品 D 断货 3 天，建议暂缓降价、保持库存，并提醒补货模块评估加快一批"                                               |

- 每条建议必须引用数据依据（哪个竞品、哪几天的数据），并附平台算出的利润影响（调用 02）。
- 人采纳后，平台记录执行时间，7 天和 14 天后自动回看销量、排名、利润的变化，形成"建议命中率"。

## 5. 看板状态【建议】

`待选对标 → 回溯建档中 → 跟踪中 → 本周总结待看 → 建议待审批 → 已执行 / 已驳回`

## 6. Agent 接口能力（MCP）

| 能力             | 说明                                                 |
| ---------------- | ---------------------------------------------------- |
| 领取跟踪任务     | 今日需快照的竞品列表                                 |
| 提交快照         | 写入每日字段（附来源）                               |
| 提交打法时间轴   | 写入回溯分析                                         |
| 提交周总结与建议 | 文字分析 + 结构化建议（类型、参数、依据）            |
| 查询我方数据     | 我方价格、销量、库存、所处阶段（上架后）             |
| 试算利润影响     | 调用 02，给定新价格 / 优惠，返回单件利润和盈亏平衡点 |

## 7. 次数控制【建议】

- 每个我方产品最多跟踪 7 个竞品；每日快照每个竞品 1–2 次调用。
- 连续 7 天无任何变化的竞品，自动降为隔天快照。
- 关键词排名默认每周 1 次。
- 估算：5 个竞品 × 2 次 × 30 天 ≈ 每个产品每月 300 次；平台在开始跟踪前显示预估。
