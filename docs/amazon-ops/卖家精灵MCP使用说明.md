# 卖家精灵 MCP 使用说明

> 写给第一次用的人。接入日期：2026-11-19；更新：2026-11-20。
>
> 给 Agent 的查询规则（工具怎么选、口径陷阱、出处怎么记）在 `.claude/skills/sellersprite/SKILL.md`，Claude 查卖家精灵时会自动读取，你不用看。

## 一、它是什么

卖家精灵是一个亚马逊数据工具，能查销量、关键词、类目行情、评论等。

「MCP」可以理解成一根数据线：接上之后，Claude 就能直接去卖家精灵查数据，不用你自己登录网站、导出表格再贴过来。

**你只需要用大白话提问，Claude 会自己决定去查什么。**

## 二、怎么用

### 第 1 步：新开一个会话

接入之后，要**新开一个会话**才生效。接入当时的那个会话里用不了。

### 第 2 步：确认连上了

在终端里运行：

```bash
claude mcp list
```

看到 `ss_mcp` 那一行后面是 `✔ Connected` 就说明正常。

### 第 3 步：直接用中文提问

不需要记任何命令。像跟同事说话一样问就行，例如：

- 「帮我查一下 B0XXXXXXXX 这个产品最近一年每个月卖多少」
- 「garlic press 这个词现在每月搜索量多少？」

### 提问的三个小技巧

1. **说清楚查谁**：给出 ASIN（产品页网址里 B0 开头的那串 10 位编号），或者给出英文关键词。
2. **说清楚站点**：我们做美国站，问的时候带一句「美国站」更稳妥。
3. **说清楚时间**：比如「近 30 天」「最近 12 个月」。不说的话，不同数据的默认时间不一样（产品月销量默认近 12 个月，关键词走势默认近 36 个月，类目和产品筛选默认近 30 天），想看哪段就直接说。

## 三、它能查什么

下面按「你想知道什么」来分类，右边是可以直接照抄的问法。

### 1. 查某个产品（竞品分析）

| 想知道                           | 可以这样问                                              |
| -------------------------------- | ------------------------------------------------------- |
| 基本信息：标题、价格、评分、排名 | 「查一下 B0XXXXXXXX 的基本信息」（一次最多 20 个）      |
| 每个月卖多少                     | 「B0XXXXXXXX 最近 12 个月的销量趋势」                   |
| 最近每天卖多少                   | 「B0XXXXXXXX 最近 30 天每天的销量估算」                 |
| 价格和排名的历史变化             | 「看一下 B0XXXXXXXX 的历史价格和排名走势」              |
| 买家评价，尤其是差评             | 「把 B0XXXXXXXX 的 1–3 星差评拉出来，总结主要抱怨什么」 |
| 五点描述和主图                   | 「看一下 B0XXXXXXXX 的五点描述和主图」                  |
| 它的流量从哪些词来               | 「B0XXXXXXXX 主要靠哪些关键词带来流量」                 |
| 它的广告怎么打的                 | 「B0XXXXXXXX 的广告活动情况」                           |
| 买家还会一起看、一起买什么       | 「B0XXXXXXXX 的关联产品有哪些」                         |

### 2. 查关键词

| 想知道                      | 可以这样问                                                |
| --------------------------- | --------------------------------------------------------- |
| 一个词现在的搜索量、购买率  | 「garlic press 现在的搜索量和购买率」（一次最多 20 个词） |
| 一个词过去几个月的变化      | 「garlic press 过去一年的搜索量走势」                     |
| 找更多相关的词              | 「围绕 garlic press 帮我扩展相关关键词」                  |
| 这个词打广告贵不贵          | 「garlic press 的广告竞价和转化情况」                     |
| 是不是季节性产品            | 「garlic press 的谷歌搜索热度走势」                       |
| 亚马逊官方搜索词排名（ABA） | 「查 garlic press 的 ABA 排名」（要明确说出 ABA 三个字）  |

### 3. 查类目（选品）

| 想知道                     | 可以这样问                                                                     |
| -------------------------- | ------------------------------------------------------------------------------ |
| 找到某个类目               | 「帮我找厨房小工具相关的类目」                                                 |
| 按条件筛选类目             | 「筛选月销量适中、评论数门槛低的类目」                                         |
| 一个类目的整体情况         | 「这个类目的市场报告」                                                         |
| 头部是不是被垄断了         | 「这个类目前几名的品牌和卖家占了多少销量」                                     |
| 价格、评分、上架时间的分布 | 「这个类目的价格分布和新品占比」                                               |
| 类目的需求趋势             | 「这个类目近两年的需求走势」                                                   |
| 排名第几大概卖多少         | 「厨房大类里排名 5000 的产品，一天大概卖多少单」（只认大类排名，不认小类排名） |

### 4. 查不了的

| 想知道                | 怎么办                                                                                    |
| --------------------- | ----------------------------------------------------------------------------------------- |
| 商标有没有被注册      | 卖家精灵 MCP 没有商标查询功能。去 USPTO（tmsearch.uspto.gov）查，或让 Claude 告诉你怎么查 |
| 专利                  | 第一期人工查（USPTO、WIPO）                                                               |
| 1688 采购价、头程运费 | 不在卖家精灵里，见需求-01、需求-02                                                        |

## 四、需要知道的几件事

1. **数字是估算，不是亚马逊官方的精确数据。** 销量、搜索量都是卖家精灵用自己的方法推算的，适合用来比较和看趋势，不要当成精确值。只有「类目需求报告」和 ABA 数据来自亚马逊官方。
2. **查询会消耗卖家精灵账号的额度。** 查不到结果不扣，但别反复查同一个东西。评论的「扩展版」（一次最多 500 条）比较慢，大约要 2 分钟，没必要时用普通版（100 条）就够了。
   - 一份完整的选品报告大约要查 10–20 次。Claude 估计要查 20 次以上时，会先告诉你打算查什么，等你同意再查。
   - 卖家精灵限制每分钟最多 40 次，几个人同时大量查询可能会被暂时拦住，稍等再试。
   - 当天查过的数据存在 `local/选品数据/` 下，Claude 会优先用存好的，不重复查。
3. **冷门产品、冷门词可能查不到。** 卖家精灵没收录的就返回空，这是数据没覆盖到，不是出错。
4. **「关联产品」不等于「同类产品」。** 买家一起买的东西经常跨类目，看着不相关是正常的。
5. **数据都带出处。** Claude 导出的 Excel 里有一张「出处」表，写着每个数字是用哪个功能、哪天、什么口径查的。毛利率这类 Claude 自己算的数字会标【粗算】，只用于初筛，正式结论等成本引擎。
6. **只用来了解市场，不要照抄竞品。** 竞品的图片、文案只用于分析打法，不能直接搬来用。
7. **筛选标准用我们自己的。** 月销、售价、垄断程度这些门槛以 `docs/amazon-ops/需求-01-选品.md` 第 6 节为准。官方提示词 PDF 里的数字（比如「评论不到 200、月销超过 300」）只是例子，照抄时把数字换掉，或者干脆不写数字，让 Claude 按我们的标准来。

## 五、怎么移除

不想用了，或者密钥泄露了需要重新配置，在终端运行：

```bash
claude mcp remove ss_mcp -s local
```

运行后新开会话，Claude 就不能再查卖家精灵了。这只是断开连接，**不会影响你的卖家精灵账号和里面的数据**，随时可以重新接入。

## 六、怎么重新接入

把下面命令里的 `你的密钥` 换成卖家精灵后台给你的那串密钥，再运行：

```bash
claude mcp add --transport http ss_mcp https://mcp.sellersprite.com/v2/mcp --header "secret-key: 你的密钥"
```

### 用 Codex 的同事

Codex 的命令行不支持加自定义请求头，需要改 Codex 的配置文件 `~/.codex/config.toml`，加上：

```toml
[mcp_servers.ss_mcp]
url = "https://mcp.sellersprite.com/v2/mcp"
env_http_headers = { "secret-key" = "SELLERSPRITE_SECRET_KEY" }
```

再在终端的启动文件（如 `~/.zshrc`）里设置环境变量 `SELLERSPRITE_SECRET_KEY` 为你的密钥。这样密钥不写在配置文件里。改完重开 Codex，运行 `codex mcp list` 确认连上。

**密钥相当于密码，不要写进文档、不要发到群里。** 本文档故意没有写真实密钥。如果怀疑密钥泄露，去卖家精灵后台重新生成一个，然后先移除、再用新密钥接入。

## 七、常见问题

**问：我问了，但 Claude 说没有卖家精灵工具？**
答：多半是没有新开会话。新开一个再试；还不行就运行 `claude mcp list` 看是不是 `✔ Connected`。

**问：显示连接失败？**
答：先检查网络；再检查密钥是否过期或被重新生成过。密钥变了就按第五、六节先移除再重新接入。

**问：同事也想用怎么办？**
答：这次的配置只对当前这台电脑上的这个项目生效。同事需要在自己电脑上按第六节操作一遍。

**问：有没有现成的提问模板？**
答：项目的 `local/参考资料/` 目录下有一份《卖家精灵 MCP 场景使用提示词.pdf》，是卖家精灵提供的 15 个场景提问示例，可以对照着用，记得把里面的筛选数字换成我们的（见第四节第 7 条）。最常用的几个场景已经按我们的口径写进了 Agent 规则，直接说「帮我在 XX 大类里找细分类目」「帮我出一份 XX 的选品报告」就行。
