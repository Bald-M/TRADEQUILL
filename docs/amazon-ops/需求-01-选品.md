## 1. 一句话说明

做一个团队内部使用的选品协作平台：**人在 TradeQuill 桌面端分配和评审选品任务；任意 AI Agent（Claude、Codex、DeepSeek 类 Agent 等）通过标准接口接入，自动取数据、按手册方法筛选和写报告；成本按真实物流报价（分淡旺季）精确核算；结果同步到团队的在线协作文档。**

## 2. 背景与目标

### 2.1 背景

- 团队是亚马逊新手，公司和店铺账号已有，还没有产品。【已确认】
- 手册结论：选品决定后续所有动作的上限；方法是"大量看数据 + 用清单和数字做判断"，行动量要求是**看 5000 款以上 → 写 50 份以上选品报告 → 精选 3–5 款打造**。
- 这个量靠人工逐个查、逐张填表做不到，需要 Agent 批量干活、人做判断。
- 新手最容易算错的是成本：同一个产品，淡季海运和旺季空运的头程能差几倍，FBA 配送费和仓储费在旺季也会上涨。成本算不准，利润和压款判断就全错。

### 2.2 目标

| 目标             | 衡量方式【建议】                                                 |
| ---------------- | ---------------------------------------------------------------- |
| 把选品漏斗跑起来 | 每月产出 ≥ 50 份合格选品报告                                     |
| 结论可信         | 报告中每个关键数字都能追溯到数据来源                             |
| 成本算得准       | 头程、FBA、仓储按发货时间对应的真实费率计算，淡季 / 旺季分别给出 |
| 守住预算         | 推荐产品都在 5 万启动资金能压得起的范围内                        |
| Agent 可替换     | 换一个 Agent 跑同一任务，筛选口径和计算结果一致                  |
| 可扩展           | 新增数据源、换掉腾讯文档时，不需要推倒重来                       |

## 3. 范围

### 3.1 要做

- 任务看板与状态流转（人建任务、Agent 领任务、实时同步）
- 选品初筛与「选品简化表」
- 「选品报告」（手册六部分）
- 淡季 / 旺季成本（调用 02）
- 团队评审（留 / 砍 / 待定 + 意见）
- 选品相关的 Agent 接口能力
- 1688 取价
- 定款交接：对标竞品清单（给 03）、首批备货方案（给 04）

### 3.2 不在本模块

- 广告投放与优化（手册第 5 章）
- 竞品每日跟踪与模仿 → 见 03
- 补货与发货 → 见 04（首批方案由本模块定款时触发）
- Listing 撰写（手册第 3 章）
- 自动下单采购、自动上架、自动试发布
- 自研在线协作文档（只预留接口）
- 除卖家精灵以外的选品数据源（只预留接口）
- 对外售卖 / 多租户

### 3.3 反目标（做出来了也算失败）

- 推荐出"7 盲 2 傻"产品：大热 3C、新奇特、季节 / 节日品、医疗器械 / 大件 / 需安装 / 需美国资质、侵权擦边品等。
- 推荐的产品按 5 万预算压不起货（以首批分批方案的资金占用最高点为准）。
- 报告里出现无来源的数字，或 Agent 自己"估"了一个数冒充查询结果。
- **用过期报价或全年统一价算成本**，导致旺季发货时利润被高估。
- 一天多次运行把整月卖家精灵次数提前用光。
- 卖家精灵或 1688 的账号 / 密钥泄露，或因违规抓取被封。

## 4. 核心流程

### 4.1 选品漏斗（手册 2.11、2.16）

```
① 建任务     ② 撒网初筛      ③ 简化表        ④ 选品报告      ⑤ 评审        ⑥ 定款前排雷
人指定类目 → Agent 从数据  → 平台算硬指标 → Agent 补齐   → 人决定     → 人线下执行，
或关键词     源批量拉候选     和淡旺季成本    六部分数据      留/砍/待定    平台给清单
             排除 7盲2傻      Agent 补 1688价  平台出报告
```

### 4.2 看板状态【建议】

`待领取 → 初筛中 → 待补价 → 简化表完成 → 报告生成中 → 待评审 → 已留 / 已砍 / 待定 → 排雷中 → 定款`

- 任一状态可进入"异常"（数据源报错、次数不足、数据缺失、**费率过期**），由人处理后回到原状态。
- 每个状态变化实时推送给所有在线成员，并同步到在线协作文档。

### 4.3 一天的典型使用场景【建议，待确认】

1. 早上：运营在看板上建 2–3 个"待筛类目"任务。
2. 白天：Agent 自动领走任务，初筛结果和报告陆续出现在看板上；一天可多轮。
3. 下午：团队在 TradeQuill 或腾讯文档里查看结果，在 TradeQuill 里评审，标"留 / 砍"并写理由。
4. 物流维护人收到货代新报价时更新费率库，平台自动重算受影响产品的成本并提示变化。
5. 负责人随时查看当月次数消耗和预算。

## 5. 功能需求

### F1 任务看板

- 按 8.2 的状态分列展示任务和产品卡片；支持筛选（类目、状态、负责人、Agent）。
- 人可以：新建任务（类目节点 / 关键词 / 竞品 ASIN）、指派、暂停、取消、重跑。
- 多人同时操作实时同步，能看到"谁正在看 / 改哪一条"。

### F2 选品简化表

| 分组                              | 列                                                                            |
| --------------------------------- | ----------------------------------------------------------------------------- |
| 基本信息                          | 序号、中英文品名（核心关键词）、主图、ASIN、类目、1688 采购价及链接           |
| 手册六项打勾                      | 刚需、低价、偏冷门（BSR 日销 50–150）、轻小、功能单一、有想象空间             |
| 硬指标（平台计算）                | 月销量、售价、重量、尺寸、尺寸分段、垄断系数、核心词 CPC                      |
| 成本（平台计算，淡季 / 旺季两列） | 头程、FBA 配送费、月仓储费、关税、到岸成本、毛利率、ROI、压款估算、采购价上限 |
| 结论                              | 是否通过、未通过原因、备注（组合思路 / 风险）                                 |

- 六项打勾由 Agent 判断并给出一句理由；硬指标和成本全部由平台计算。
- 不达标的指标标红，不直接删除，人可以手动"放行"并留下理由。
- 成本列默认按"计划发货日期"取费率，同时并排显示淡季和旺季两种情况。

### F3 选品报告（手册 2.11 六部分）

1. **产品基本情况**：中英文名、一二级类目、产品简介、选择理由（需求端 / 竞品端 / 供应端）。
2. **成本结构**：按物流渠道（快递 / 空运 / 海运快船 / 海运慢船）× 时段（淡季 / 旺季）的利润矩阵；BSR 前 100 及搜索前 2–3 页价格区间；推荐发货方式组合（手册建议 3–4 种方式拆分，如 500kg 按 50–150–300 拆）。
3. **需求与竞争**：核心词月搜索量、CPC、关键词集中度、搜索结果数、BSR 销量、垄断系数（Listing / 品牌 / 卖家三个口径）、自营份额；按头 / 腰 / 尾抽样 ≥ 7 个竞品。
4. **生命周期**：搜索趋势，判定为刚需型 / 季节型 / 爆发型 / 不稳定型；季节型产品给出最晚发货时间点（按各渠道时效倒推）。
5. **专利与商标**：商标库结果；专利第一期提示人工查询。
6. **评论分析**：好评提炼卖点、差评找改进点。

- 报告由平台按固定模板渲染，Agent 只填数据和文字分析段落。
- 报告支持版本：重跑或费率更新后生成新版本，可对比。

### F4 评审

- 每份报告可被多人评分（1–5）和写意见，负责人给最终结论：留 / 砍 / 待定。
- 结论为"留"的产品自动生成「定款前排雷清单」（手册 2.16）：试发布观察 2–3 天 → 至少 3 家拿样 → 砍价 → 重算利润。

### F5 规则与参数配置

- 负责人可在 TradeQuill 里维护：筛选阈值、汇率、排除类目 / 关键词黑名单、报告模板。
- 规则修改留历史版本；每份结果记录当时用的规则版本。

### F6 Agent 接口能力（选品部分）

- 由每台电脑上的 TradeQuill 本地助手提供 **MCP 服务**（见总览第 9、10 节）。
- 接口能力草案：

| 能力              | 说明                                                       |
| ----------------- | ---------------------------------------------------------- |
| 领取任务          | 按优先级领取一个待处理任务，领取后加锁防止重复             |
| 读取规则          | 获取当前筛选标准、报告模板                                 |
| 查询缓存          | 先查平台里是否已有某 ASIN / 关键词的近期数据               |
| 提交候选产品      | 批量写入产品原始数据（附来源信息）                         |
| 提交 1688 价格    | 写入采购价、链接、起订量、阶梯价                           |
| 提交报告段落      | 写入报告各部分的数据和分析文字                             |
| 试算成本          | 给定重量尺寸、售价、采购价、发货日期，返回各渠道淡旺季成本 |
| 更新进度 / 报异常 | 进度、失败原因                                             |
| 登记次数消耗      | 记录本次调用了哪些数据源工具、消耗多少次                   |

- 每个 Agent 有独立身份（名称 + 接入凭证），便于追溯和停用。

### F7 次数控制（选品部分）

- 实时显示当月卖家精灵已用 / 剩余次数。
- 每个任务开跑前预估消耗，超出当日 / 当月限额时暂停并提醒负责人。
- 评论抓取默认上限【建议】：每个产品最多 100 条（约 5 次）。
- 同一 ASIN / 关键词在有效期内（【建议】7 天）优先用缓存。
- 多个数据源时分别统计。

### F8 定款交接（新增）

- 产品定款时，平台自动生成两份交接内容：
  - **对标竞品清单**（从选品报告的头 / 腰 / 尾竞品里挑 3–7 个，附理由），交给 03 开始每日跟踪。
  - **首批备货与分批发货方案**（件数、批次、渠道、资金占用最高点），交给 04；方案超出 5 万预算时不允许定款，需人调整。
- 选品报告第 2 部分"成本结构"增加一行：按推荐分批方案算出的**单件完整成本**（含预计在库仓储费，见 02）。

成本计算规则（头程报价、FBA 配送费、仓储类费用、关税、公式）已移到 [02 成本引擎与物流费率库](需求-02-成本与物流费率库.md)。

## 6. 业务规则

### 6.1 硬指标（手册 2.8）

| 指标                                    | 通过标准                                        |
| --------------------------------------- | ----------------------------------------------- |
| 垄断系数（前 3 名销量 ÷ 前 100 名销量） | < 50%，< 40% 更佳                               |
| 精准大词 CPC × 10                       | < 售价；售价 < $10 时 CPC ≤ $1.2                |
| 毛利率（海运）                          | > 30%（空运 > 20%）；**按旺季费率也要单独判断** |
| ROI                                     | > 90%                                           |
| 自营份额                                | 自营市场份额明显高于自营数量占比时标红          |

### 6.2 初筛条件（手册新手低价品参考）

月销 1500–4500 单，售价 $10–20，重量 ≤ 300g，FBA 配送费 ≤ $5。

### 6.3 预算约束【建议】

- 按目标日销 20 单估算压款 ≤ ¥30,000，超过标红。
- 到岸成本（采购 + 头程 + 关税）尽量 ≤ ¥20。

### 6.4 排除规则（"7 盲 2 傻"）

默认黑名单【建议】：3C 电子、带电 / 电池、液体粉末、医疗器械、大件、需安装、需美国资质准入、节日 / 季节性、新奇特（核心词月搜索量 < 5000 视为疑似）。负责人可增删。

| 关税税率                                             | 人工维护                                                                                                   | 带生效期和来源                                                            |
