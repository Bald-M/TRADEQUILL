# 02 成本引擎与物流费率库 · 需求

> 所属：[00 总览](需求-00-总览.md)　｜　被 [01 选品](需求-01-选品.md) 和 [04 补货与发货](需求-04-补货与发货.md) 调用
> 版本 v0.14 · 2026-11-20 · 标记含义见总览

## 1. 目标

成本按真实报价、发货时间和库存在仓时间精确计算：淡季、旺季分开算；头程、FBA 配送费、仓储类费用、关税都带生效期；任何一个费用都能追溯到用的是哪张表、哪一条。

## 2. 头程报价库

每条报价记录：

| 字段       | 说明                                                                      |
| ---------- | ------------------------------------------------------------------------- |
| 货代       | 名称、联系人                                                              |
| 渠道       | 商业快递 / 空派 / 海运快船（美森、以星等）/ 海运慢船 / 海卡 / 海派 / 铁运 |
| 目的地     | 美西 / 美中 / 美东，或具体 FBA 仓库代码；海外仓 / AWD（若采用）           |
| 计费方式   | 按公斤 / 按立方米；体积重除数（5000 / 6000 / 7000 / 不计抛）              |
| 重量段价格 | 如 21–44kg、45–99kg、100kg+ 各段单价                                      |
| 起运量     | 最低计费重量或体积（**补货分批时的下限**）                                |
| 附加费     | 燃油、旺季、报关、偏远、带电 / 磁检等                                     |
| 时效       | 承诺时效（天）；平台另记"实际时效"（见 04 的货件记录）                    |
| 包税       | 包税 / 不包税                                                             |
| 生效期     | 开始、结束日期                                                            |
| 来源       | 原件附件、录入人、录入时间                                                |

**录入方式【已确认】**

| 形式       | 录入方式                                               |
| ---------- | ------------------------------------------------------ |
| Excel      | 按货代建「列映射模板」，第一次手动对应列，之后一键导入 |
| 图片 / PDF | 上传后由 Agent 识别成报价草稿                          |
| 微信文字   | 粘贴后由 Agent 提取成报价草稿                          |

- 所有导入先进入「待确认报价」，物流维护人对照原件核对后才生效；未确认的不参与计算。原件永久保存。
- 报价没写有效期时默认 14 天【建议】，到期前 3 天提醒。
- 保留历史报价，画价格走势；新报价生效后自动重算受影响的选品和补货计划，列出变化最大的产品。
- 选品成本同时给出"按当前报价"和"按近 12 个月最高价"两种结果【建议】。
- 计算时按"计划发货日期"取生效期内报价；多家货代时默认取最低价并显示其他家。

## 3. FBA 配送费

- 内置美国站 FBA 配送费率表，**按生效期分版本**（如 2025 非旺季、2025 旺季 10-15 至次年 01-14、2026-01-15 起新费率）。
- 计算：确定尺寸分段 → 体积重（长×宽×高 英寸 ÷ 139）→ 取实重与体积重较大者（小号标准件只按实重）→ 按售价档查表（手册 6.5）。
- 2026-04-17 起另有 3.5% 燃油与物流附加费（第三方资料，需对照卖家后台核实）。附加费做成独立参数，可单独开关和修改。

## 4. 仓储类费用（新增：精算，不再只做提示）

补货计划需要知道"多放一个月要多花多少钱"，所以第一期就要按月精算。所有费率、阈值都做成带生效期的参数表，**以卖家后台公告为准**，下表只是手册和 2026 年公开资料的当前口径。

| 费用             | 何时产生                                                              | 计算口径                                                                         | 对补货的意义                                                         |
| ---------------- | --------------------------------------------------------------------- | -------------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| 月度仓储费       | 只要有库存                                                            | 单件体积（立方英尺）× 月平均库存 × 月费率；标准尺寸 1–9 月 $0.78、10–12 月 $2.40 | 旺季在库每件的成本是淡季的 3 倍，Q4 前要更精确地控制在库量           |
| 仓储利用率附加费 | 专业账户、首个货件超过 365 天、日均占用 ≥ 25 立方英尺、利用率 > 22 周 | 按利用率分档，每立方英尺 $0.44–$1.88                                             | 新卖家 52 周内不收；但要监控利用率，压货会推高它                     |
| 超龄库存附加费   | 库龄超过 180 天                                                       | 按库龄段每立方英尺加收（181–210 天 $0.50、211–240 天 $1.00，再往后更高）         | 团队规则"一批货 3 个月内卖完"可避开                                  |
| 低库存水平费     | 过去 30 天和 90 天的历史供货天数都少于 28 天                          | 加在配送费里；2026-01-15 起按 FNSKU 计算                                         | **货也不能发太少**：补货下限要保持 ≥ 28 天供货【需核实新卖家豁免期】 |
| 入库配置服务费   | 创建货件时选择"最少拆分"等配置                                        | 按件、按重量段收取；选亚马逊优化拆分可减免                                       | 分批越多、每批越小，这笔费用的占比可能越高，要和仓储费一起算         |
| 入库缺陷费       | 货件有标签、包装、预约等问题                                          | 2026 年起合并为单项，平均约 $0.60 / 件                                           | 发货规范清单的一部分                                                 |
| 移除 / 弃置费    | 撤仓或销毁                                                            | 按件                                                                             | 清货决策时和"低价清货"比较                                           |
| 库容限制         | 按月、按仓储类型                                                      | 卖家后台"容量监视器"；受 IPI 影响                                                | 补货量的硬上限                                                       |

- 新卖家豁免：手册记载新注册专业卖家首件库存接收后 365 天内不收低库存水平费，新卖家 52 周内不收仓储利用率附加费；平台记录"首件库存接收日"并自动判断豁免是否还在，到期前提醒。【需对照卖家后台核实当前规则】

## 5. 关税【已确认：包税和不包税渠道都有】

- 包税渠道：关税已含在头程单价里。
- 不包税渠道：按 HTS 编码查税率（含对华附加关税），带生效期；关税 = 申报货值 × 税率。
- 税率表人工维护，标注来源和更新日期；变化后一键重算。

## 6. 计算公式

| 名称                     | 公式                                                                                 |
| ------------------------ | ------------------------------------------------------------------------------------ |
| 计费重                   | max(实重, 长×宽×高(cm) ÷ 渠道体积重除数)；按方计费的渠道按体积                       |
| 头程                     | 计费重 × 生效期内对应重量段单价 + 分摊附加费                                         |
| 佣金                     | 售价 × 15%（默认，按类目可配）                                                       |
| 关税                     | 申报货值 × 税率（包税渠道为 0）                                                      |
| 国内处理费（新增）       | 贴标、包装、装箱的人工和材料，按件；工厂已代贴标的产品只算装箱                       |
| 到岸成本                 | 采购 + 国内处理费 + 头程 + 关税                                                      |
| 盈亏平衡点               | 到岸成本 + FBA 配送费 + 佣金                                                         |
| 毛利 / 毛利率 / ROI      | 售价 − 盈亏平衡点；毛利 ÷ 售价；毛利 ÷ 到岸成本                                      |
| **单件在库成本**（新增） | Σ 每个在库月的（单件体积 × 当月仓储费率 + 适用的附加费），按"预计在库天数"分摊到每件 |
| **单件完整成本**（新增） | 盈亏平衡点 + 单件在库成本 + 入库配置费 + 资金占用成本（可选，按月利率配置）          |
| 压款                     | 到岸成本 × 日销 × 周转天数；补货模块按实际批次逐日计算资金曲线（见 04）              |
| 采购价上限               | 售价 × 55% − 头程 − FBA 配送费 − 关税（统一换算成人民币）                            |

金额统一以人民币和美元双显示，汇率可配置并记录生效日期。

## 7. 输出与接口

- 每个产品输出"渠道 × 时段"成本矩阵（淡季发货 / 旺季发货 × 空派 / 快船 / 慢船），含到岸成本、毛利率、ROI、时效。
- 给补货模块的接口：输入"发货日期、渠道、件数、预计每日销量"，返回到仓日期、头程总额、按月的在库件数和仓储类费用、单件完整成本。
- Agent 可调用的能力：试算成本、查询某渠道当前有效报价、提交报价识别草稿（只能进"待确认"）。
