# 产品档案与轻量知识库

需求来源：[#11](https://github.com/Bald-M/TRADEQUILL/issues/11)、[#23](https://github.com/Bald-M/TRADEQUILL/issues/23)，为 [AI 辅助 Epic #17](https://github.com/Bald-M/TRADEQUILL/issues/17) 提供离线资料基础。

## 产品主数据

“产品与知识库”中的产品档案维护稳定 ID、产品编号、名称、名称/值参数、计量单位、起订量与交期。起订量可以未知；数量有值时必须使用明确单位。交期按天记录，并用说明区分生产准备时间和运输时间，不把未知值当作零。

产品编号不可重复。搜索按编号和名称匹配；详情与复制资料来自同一份档案。归档保留 ID 与历史资料关联，归档状态和更新时间可见。现有询盘、样品及报价中的自由文本原样保留，不自动映射产品，也不修改历史业务记录。

## 资料录入与确认

资料可以关联产品或作为通用资料。支持手动文本、FAQ，以及 TXT、Markdown 和含文本的 PDF。资料保存标题、来源说明、标签、确认状态、对外可用/仅内部范围和人工冲突说明。

文件先提取并显示预览，由用户检查产品关联、来源和内容后确认保存。每文件最多 5 MiB，最多 100 份资料；所有资料副本、历史文本和待确认预览合计最多 500 MiB，达到上限时保留当前版本，由用户主动删除不再需要的资料。PDF 最多 100 页、提取文字最多 50 万字符，解析最多 10 秒。扫描 PDF 或无有效文本的文件会说明无法提取，不进行 OCR。解析失败不替换已保存资料，相同文件有去重反馈。文件以应用管理的内容保存，不接受任意本机路径读写。

## 搜索、版本与删除

检索在本机完成，不需要 AI 服务或联网。可选全部或指定产品、通用资料和标签，并用关键词搜索；结果显示匹配片段及资料版本，PDF 结果保留页码。打开结果可以查看原文。

更正内容会创建新版本，并保留资料的稳定标识。归档资料不进入新检索；更新后新检索只使用当前版本。删除资料会清除应用持有的文件内容、解析文本及派生搜索数据，保留产品档案和已有客户/报价业务。引用旧版本或已删除资料的历史结果不能当作当前有效内容。

产品档案是结构化事实来源。资料中的说法与产品字段不一致时，由用户核对并记录冲突，不自动覆盖产品参数、起订量或交期。草稿、已归档或仅内部资料不会因为录入就成为可对外引用的资料。

## 交付边界

本阶段是产品档案和本地资料管理。线索智搜与评估、产品知识问答、竞品报告，以及共享模型/搜索配置按 Epic #17 的独立需求交付；未验收的功能不作为已可用能力。资料导入不等同于业务表格导入或包含数据库和附件的完整备份。

数据库升级通过 schema 3 事务迁移保留 schema 2 的业务记录；再次启动不清空数据，高版本 schema 拒绝降级。升级前的手动备份方式保持为完全退出应用后复制整个应用数据目录。实际平台与受测版本见 [验收记录](validation.md)。
